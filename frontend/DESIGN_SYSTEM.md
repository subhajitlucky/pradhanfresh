# PradhanFresh — "Harvest Ledger" design system

Every page must follow this contract. Tokens are generated by Tailwind v4 from the
`@theme` block in `src/styles/index.css` — there is no `tailwind.config.js`.

## Concept

A fifty-year-old family produce market, presented like a well-set letterpress almanac:
warm newsprint ground, ink type, tomato-crate ember as the single accent, hairline rules
instead of shadows-and-cards, and generous editorial whitespace. It should read as a
**ledger**, not a SaaS dashboard.

**Reject:** purple/blue gradients, glassmorphism, `rounded-[40px]` everywhere, drop
shadows on every element, Inter/Roboto, purple-on-white, emoji as icons.

## Tokens

### Colour

All values are chosen so that every text/background pairing in the system clears
**WCAG AA** (verified: 563/563 sampled text nodes across 9 routes).

| Class | Value | Use |
| --- | --- | --- |
| `bg-paper` | `#f4efe4` | page ground |
| `bg-paper-deep` | `#e9e0cc` | alternating bands, wells, skeletons |
| `bg-paper-card` | `#fcfaf4` | raised surfaces, inputs |
| `bg-paper-ink` | `#1c1813` | inverted panels, footer, ticker |
| `text-ink` / `ink-2` / `ink-3` / `ink-4` | `#14110d` → `#9c9280` | primary → disabled |
| `border-rule` / `rule-soft` / `rule-strong` | `#d5cbb4` → `#14110d` | hairlines |
| `bg-ember` · `text-ember` · `text-ember-deep` · `bg-ember-soft` | `#b03a22` family | **the** accent: primary CTA, active state, price emphasis |
| `bg-leaf` · `text-leaf` · `text-leaf-deep` · `bg-leaf-soft` | `#3f6b3a` family | success, organic, "in stock" |
| `bg-citrus` · `text-warn` · `bg-citrus-soft` | `#b8781a` family | ratings, warnings, **accents on dark grounds** |
| `text-ok` `text-warn` `text-bad` | semantic | status only |

Measured contrast:

| Pair | Ratio |
| --- | --- |
| `text-ember` on `bg-paper` | 5.27:1 |
| `text-ember` on `bg-paper-card` | 5.79:1 |
| `text-ink-3` on `bg-paper` / `card` / `deep` | 5.24 / 5.76 / 4.58 |
| `text-citrus` on `bg-paper-ink` | 4.83:1 |

**Three rules that exist because the numbers failed at some point:**

1. **Never `text-ember` on `bg-paper-ink`.** Ember is tuned for paper grounds and
   only reaches 2.9:1 on the ink block. Use `text-citrus` for accents there —
   including overriding `.eyebrow` with `className="eyebrow text-citrus"`.
2. **`text-ink-4` is for disabled state only.** It is 2.9:1 and fails AA. Never use
   it for content — strikethrough prices and step numerals use `text-ink-3`.
3. **Don't invent new colours.** If a pairing seems to need a new value, darken an
   existing token instead and re-check it with the contrast rule below.

```bash
# verify any new colour pairing before shipping
node -e "const L=h=>{const [r,g,b]=[1,3,5].map(i=>parseInt(h.slice(i,i+2),16)/255).map(v=>v<=.03928?v/12.92:((v+.055)/1.055)**2.4);return .2126*r+.7152*g+.0722*b};
const c=(a,b)=>{const x=L(a),y=L(b);return((Math.max(x,y)+.05)/(Math.min(x,y)+.05)).toFixed(2)};
console.log(c('#b03a22','#f4efe4'))"   # → 5.27
```

### Type

- `font-display` (**Fraunces**) — every `h1`–`h6`, prices, big numbers. Always `font-semibold`.
- `font-body` (**Archivo**) — all body copy and UI.
- `font-mono` (**JetBrains Mono**) — eyebrows, labels, SKU, order numbers, tabular figures. Always `uppercase tracking-[0.12em]`-ish.

Prefer the custom `.eyebrow`, `.shell`, `.tnum`, `.wipe`, `.stagger`, `.rule-t/.rule-b`
classes over re-implementing them.

### Radius, shadow, motion

- Radius: `rounded-sm/md/lg` (4/8/14px). Pills only for badges (`rounded-full`).
- Shadow: only `shadow-sheet` / `shadow-lift` / `shadow-float`. Never a bare `shadow-xl`.
- Buttons use `shadow-[0_2px_0_0_...]` (a printed rule) and `active:translate-y-px`.

### Rules that are not negotiable

1. **No `useState`+`useEffect` fetching.** Use the React Query hooks in `lib/catalog.ts`.
   There is no `ApiError` leaking into components — use `errText(err)`.
2. **Never hand-roll a button, input, card, badge, empty state, spinner or skeleton.**
   If a primitive is missing, add it to `src/components/ui/` instead of inlining.
3. **Every page needs an `<h1>`.** Heading order must not skip a level.
4. **Every async surface needs loading + error states** — use `LoadingBlock`, `ErrorState`
   (pass `onRetry={refetch}`), `EmptyState`.
5. **Every icon-only control needs an accessible name** (`aria-label`).
6. **Every form control needs a real `<label>`** — use `Input`/`Select`/`Textarea`,
   which wire `id`, `htmlFor`, `aria-invalid` and `aria-describedby` automatically.
7. **Results that change on interaction get a live region** (`role="status"`,
   `aria-live="polite"`). Cart counts especially.
8. **Use `ProseImage`**, never a raw `<img>` — it resolves `/uploads/…` backend paths and
   degrades gracefully when an image 404s.
9. **`noUnusedLocals`/`noUnusedParameters` are on and `strict` is on.** The build must
   pass `tsc` clean. No `any`, no `@ts-ignore`.

### Motion

- Page/section entrances: `.stagger` with an incrementing `style={{ '--i': n }}`, or the
  `<Stagger index={n}>` helper.
- Hover: `hover:-translate-y-1` + `hover:shadow-lift` for cards; `hover:border-ink` for controls.
- `prefers-reduced-motion` is handled globally — do not add `motion-*` infinite loops.
